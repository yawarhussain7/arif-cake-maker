# CakeDelight (React + Tailwind CSS v4)

    npm install
    npm run dev      # http://localhost:5175

Routes: `/`, `/cakes`, `/custom-order`, `/occasions`, `/about`, `/contact`, `/cart`, `/faqs`.

Images: drop your files into `public/images/` using the names in `src/data/index.js`
(hero-1.jpg, cat-birthday.jpg, cake-truffle.jpg, user-1.jpg ...). A cake placeholder shows until they exist.
